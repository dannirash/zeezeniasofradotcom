Three Integration Paths with Squarespace

A

Campaign Landing Page Standalone

Host sofra.html on Netlify or GitHub Pages — both free. Link it from the existing Squarespace site as a campaign-specific page (e.g. welcome.zeezenia.com). Zero disruption to the current Squarespace setup.

✅ Fastest path — live in under 30 minutes.
B

Embed Widgets Into Squarespace Hybrid

Use Squarespace's Code Block feature to embed components — the student lead form, the referral widget, the menu tabs — directly into existing Squarespace pages. Requires the Business plan ($23/mo).

⚡ Recommended — keeps one brand home, adds new features.
C

Full Squarespace Rebuild Long-term

Use sofra.html as the design blueprint for a full Squarespace rebuild. All sections, palette, and copy map directly. A developer can rebuild this in 1–2 days — one unified site with full CMS control.

📋 Best long-term investment. Full CMS control.

Publishing Roadmap — Live in 48 Hours

1

Host the HTML File

Go to netlify.com/drop. Drag sofra.html + the 4 images into the browser window. Netlify generates a live URL instantly — no account required.

~15 min · Free
2

Connect a Custom Domain

Create a free Netlify account and add a CNAME DNS record pointing welcome.zeezenia.com to Netlify. Your main Squarespace domain stays completely untouched. HTTPS is automatic and free.

~30 min · Free
3

Wire the Lead Form

Sign up at formspree.io (free: 50 submissions/mo). Create a form, copy the endpoint URL like formspree.io/f/xxxxx, and paste it as the form action. Submissions go straight to the Zeezenia inbox.

~10 min · Free
4

Add Analytics & Go Live

Create a free Google Analytics 4 property and paste the gtag.js snippet into the <head>. Share the link on Instagram, Gator1 Central, and Nextdoor Gainesville. Campaign is live.

Same day · Free
